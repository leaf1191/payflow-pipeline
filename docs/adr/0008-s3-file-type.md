# 0008. S3 파일 저장 타입 결정

## Context
직관적으로 알아보기 쉬운 json과 바이너리 기반 컬럼기준 정렬한 parquet 중 비교

## Decision
### 압축률 측면에서
바이너리 기반+컬럼 기반으로 반정형 반복이 적은 parquet이 압축률이 매우 높고, json은 압축률이 매우 낮음
압축률이 높아서 네트워크 전송 비용이 적고 같은 전송량에 더 많은 데이터를 처리할 수 있음 
### 파싱 비용 측면에서
parquet은 바이너리라 미리 정의된 스키마에 바로 매핑하면 됨. variant라도 바이너리로 텍스트 파싱 없이 바로 구조를 읽어 들임. json은 할때마다 문자열 파싱하고 타입 캐스팅까지 수행
처리속도가 parquet이 빠름

따라서 parquet으로 결정
