# 0002. (부채) kafka 권한 문제

## Context
postgre는 자체 생성한 유저로, S3는 IAM role로 인증 및 인가가 이뤄지는데, kc나 kafka는 현재 설정 기준, 누구나 커넥터 생성이 가능하고, 토픽 생성 및 데이터 쓰기 및 조회가 가능함

## Decision
우선 모든 인프라가 VPC 내에서 돌아가기도 하고 프로듀서와 컨슈머도 명확, 특히 이 프로젝트의 핵심은 데이터 파이프라인 무결성 및 멱등성 핵심이므로 우선 순위가 상대적으로 낮다고 판단하여 차후 부채로 보류, 당장은 security group으로 통제
